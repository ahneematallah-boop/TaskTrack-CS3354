# TaskTrack – Student Assignment Management System

## 1. Problem Description

College students usually have several classes, and each class has its own assignments, quizzes, exams, and deadlines. Keeping track of everything can become difficult, especially when professors use different platforms to post assignments. Students might forget about an assignment or miss a deadline because they have trouble keeping everything organized.

Our team wants to create a web application called **TaskTrack** that helps students manage their schoolwork in one place. Students will be able to add assignments, set due dates, organize their work by class, and mark assignments as completed. The main goal is to make it easier for students to stay organized and know what they need to work on next.

## 2. Stakeholders

The main stakeholders for TaskTrack are:

- **College students:** They are the main users of the application. They will use TaskTrack to organize assignments, check deadlines, and keep track of completed work.
- **Development team:** Our team of five students will be responsible for planning, designing, developing, and testing the application.
- **Professors and instructors:** They are indirect stakeholders because they assign coursework and set deadlines. However, they will not need to use the application directly.

## 3. Project Feasibility

We believe TaskTrack is a realistic project for our team because it does not require advanced technology or complicated features.

The application can be developed using common web development tools such as HTML, CSS, and JavaScript. We can also use a simple backend and database to store assignment information.

Since our team has five members, we can divide the work into smaller tasks. For example, some members can work on the user interface while others focus on the backend, testing, and documentation.

One possible challenge is making sure that assignment information is saved correctly and displayed in the right order. We plan to handle this by testing the application as we develop it.

Overall, we believe the project can be completed within the course timeline as long as we focus on the main features first.

## 4. Project Scope

### Features Included

Our application will allow students to:

1. Add assignments with a title, course name, description, and due date.
2. Edit or delete assignments.
3. View upcoming assignments in order of their deadlines.
4. Mark assignments as completed or incomplete.
5. Organize assignments by course.
6. View a dashboard showing pending, completed, and overdue assignments.

### Features Not Included

To keep the project manageable, we will not include:

- Direct integration with Canvas, Blackboard, or other school platforms.
- Automatic importing of assignments from professors.
- AI-generated study schedules or recommendations.
- Messaging or communication between students.
- Mobile applications for iOS or Android.

These features could be added in the future, but they are not necessary for the first version.

## 5. Project Goal

The goal of TaskTrack is to create a simple and useful application that helps college students manage their assignments and deadlines. By keeping everything in one place, students can spend less time trying to remember what is due and more time completing their work.

Our team plans to focus on making the application easy to use, reliable, and practical for everyday student needs.
